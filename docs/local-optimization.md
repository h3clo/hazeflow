# 로컬 최적화 점검 (2026-11-01)

배포하지 않은 변경. `codex/local-optimization` 브랜치에서 검증했다.

- 로그인 SDK를 메인 모듈에서 분리해 화면을 먼저 렌더링한다. 로그인 코드는 초기 화면 직후 로드하므로 전체 다운로드가 같은 비율로 줄었다는 뜻은 아니다.
- 백업·사진 ZIP 코드는 내보내기를 실행할 때 로드한다.
- 메인 JS: 기존 446,252 bytes → 약 189 KB (minified, gzip 전). 로그인 별도 청크 약 249 KB. HEIC 변환 청크는 기존처럼 필요할 때만 로드된다.
- 같은 자산 응답에는 전체 화면을 다시 그리지 않는다. 일별 자산 캐시 조회 간격은 5분으로 통일했다.
- 숨겨진 탭에서는 활동 시간 계산을 건너뛰고, 돌아올 때 갱신한다. 화면에 시간 라벨이 있을 때만 기록 구간을 계산한다.
- 사진의 동시 읽기를 합치고 최대 4개씩 처리한다. 계정 전환 시 임시 URL을 해제하고 늦게 도착한 이전 계정 사진을 표시하지 않는다.

검증: 단위 테스트 152개 통과, 프로덕션 빌드 성공, diff 공백 검사 통과. 별도 sandbox에서 로그인 창 진입과 JSON 백업 다운로드를 확인했다. 실제 아이폰 촬영 및 실제 계정 로그인은 이번 최적화 검증에 포함하지 않았다.

## 기능 흐름 개선

- reminder 편집에서 오늘·내일·기한 없음 빠른 선택을 제공한다.
- 선택한 목록 기준으로 상태별 숫자를 계산한다. 마지막 항목을 삭제하거나 다른 목록으로 옮겨 기존 목록이 사라지면 전체로 복구한다.
- 새 reminder에 현재 목록·오늘·중요 필터를 기본값으로 반영한다. 기존 항목의 속성은 유지한다.
- 활동의 현재 시각 버튼은 수동 시간 고정을 해제해 다시 자동 시각 갱신을 따른다.

추가 검증: 전체 154개 테스트 및 빌드 통과. sandbox에서 내일 날짜 선택 → 별도 목록에 저장 → 해당 목록 선택 → 마지막 항목 삭제 → 전체 필터 자동 복구를 확인했다. 실제 기록 변경·배포 없음.

## 메뉴 통합

13개 상위 메뉴를 오늘 / 계획 / 기록 / 돈 관리 / 돌아보기 5개로 정리했다. 계획은 캘린더·reminder·루틴·목표, 기록은 활동·일기·생활 상태/인바디·즐겨찾기, 돈 관리는 가계부·자산, 돌아보기는 주간 회고·과거 비교를 하위 메뉴로 제공한다. 같은 실행 세션 내에서는 각 그룹의 마지막 화면으로 돌아온다. 기존 오늘 화면의 바로가기도 해당 상위 메뉴와 연동한다.

검증: 156개 테스트 통과, 빌드 성공. 로컬 sandbox에서 계획 → reminder → 돈 관리 → 계획 복귀 시 reminder 유지 확인. 1280px 및 390px에서 페이지 가로 넘침 없음. 메뉴별 데이터 저장 방식은 바꾸지 않았다. 배포하지 않음.

## 대시보드 모드·용어 통일

화이트보드 모드를 대시보드 모드로 개편했다. 데스크톱에서는 reminder 포스트잇과 월간 일정 캘린더를 나란히 표시한다. 작은 화면에서는 세로로 배치한다. 날짜 선택은 모드를 벗어나지 않고 하단의 선택일 일정 목록을 갱신하며, 일정 추가·수정·실행과 reminder 추가·완료·수정은 기존 데이터에 연결한다. 캘린더는 일반 캘린더 화면의 렌더러를 재사용하며, 대시보드에서는 일정만 표시해 포스트잇과 중복되는 reminder 표시를 줄인다.

새 북마크는 #dashboard / #dashboard-all. 기존 #whiteboard 주소도 호환한다. 닫기·뒤로가기는 reminder 목록으로 돌아온다. PLAN/ROUTINE은 오늘의 흐름/루틴으로, 활동 남기기는 활동 기록으로 통일했다. reminder의 기존 분류값은 보존하고 화면·내보내기·동기화 충돌 안내에서 표시명만 통일했다.

검증: 157개 테스트 통과 및 빌드 성공. sandbox에서 포스트잇 생성, 다른 날짜 선택, 선택일 일정 생성과 표시, 뒤로가기 복귀, 이전 북마크의 전체 할 일 범위 유지 확인. 1440px와 390px에서 가로 넘침 없음. 예시 화면은 docs/dashboard-preview.png. 배포하지 않음.

## 헤더 진입점 및 화면 정렬

대시보드 진입 버튼을 모든 화면의 공통 헤더로 옮기고 reminder 안의 중복 진입 버튼을 제거했다. 다른 화면에서 열어도 tasks 대시보드를 표시하도록 동작을 수정했다. 헤더의 제목·도구줄·동기화 문구를 분리해 가변 문구와 버튼이 서로 밀어내지 않도록 했다. 좁은 화면은 도구줄을 제목 아래에 배치한다.

날짜 선택줄의 고정 최소 너비, 도구줄 버튼의 위쪽 여백, 활동 입력 버튼 정렬을 정리했다. 일반 reminder 행의 버튼을 절대 배치에서 별도 열로 바꾸고 모바일에서는 아래쪽에 배치해 긴 제목과 겹치지 않게 했다. 포스트잇 배치는 유지한다.

검증: 13개 화면 × 1280/768/390/320px(52개 조합)에서 문서 가로 넘침 없음. 가계부 헤더에서 대시보드 진입 확인. 별도 sandbox의 긴 reminder 제목과 버튼이 1280/320px 모두 겹치지 않음 확인. 테스트 157개 및 빌드 통과. 모든 변경 로컬에 유지하며 배포하지 않음.

## 주간 돌아보기

오늘 화면의 기록 건수 막대는 7일 달력으로 교체했다. 활동·일기·사진 유무를 날짜별로 표시하고 날짜를 누르면 해당 날을 연다. 주간 회고에는 근력 세트 수, 유산소 분, 수면 만족도 1~5점, 기록한 지출의 요일별 차트를 추가했다. 측정하지 않은 날은 0으로 가정하지 않고 —로 표시하며 미래 날짜는 집계에서 제외한다. 차트별 단위와 눈금은 독립적이다.

검증: 160개 테스트 및 빌드 통과. sandbox에서 운동 1건에 랫풀다운 3세트+러닝머신 20분을 기록해 두 차트에 각각 반영됨을 확인했다. 차트의 날짜 버튼으로 해당 하루 이동, 390px에서 가로 넘침 없음 확인. 배포하지 않음.

## 운동·식단·몸 변화 1차 연결

생활 상태에 날짜별 키·체중·운동 목표 저장과 최근 30일 통합 보기를 추가했다. 기존 life 저장 구조로 계정 동기화·백업·문서 내보내기에 포함된다. 과거 운동에는 해당 운동일까지의 최신 체중만 사용한다. 주요 중량 운동의 사용 근육을 종목별로 표시하고, 부위별 마지막 운동 및 직접 종료 기록 이후의 경과 시간을 표시한다. 생리학적 회복 완료나 실제 자극을 측정하지 않는다.

칼로리는 인식된 중량 근력 운동만 있는 기록에 한해, 당시 체중과 직접 입력된 시작·종료 시간을 사용한다. 1~240분만 지원하며 자동 추론한 활동 종료는 사용하지 않는다. 2024 Adult Compendium의 중량 근력 운동 3.5~6 MET 범위를 체중×시간에 곱한 휴식대사 포함 추정 범위다. 참조: https://pacompendium.com/conditioning-exercise/ . 유산소·혼합 운동, 식사 열량·영양소, 회복률, 쇼핑몰 자동 수집은 아직 미지원이다.

결제수단 입력 후보에 온누리상품권·포인트·기타 상품권 등을 추가하고 충전은 이체/사용은 지출로 기록하는 안내를 넣었다. 복합 결제나 할인 충전 자동 정산은 아직 없다.

검증: 163개 테스트 및 빌드 통과. 신체 정보 저장 후 새로고침 복원, 예시 체중 60kg/근력 60분의 210~360kcal 표시 확인. 과거 체중·미확인 시간·미분류 운동 처리와 백업 보존 테스트 포함. 390px 통합 화면 가로 넘침 없음. 실제 계정 데이터 변경 없이 sandbox에서 검증. 배포하지 않음.

## 운동 체감 기록·인바디 구간 회고

운동별 직접 느낀 부위·운동 직후 힘듦(1~5)·근육통·메모를 별도 입력·수정·삭제한다. 종목에서 추정한 사용 근육과 분리한다. 기존 logs의 workoutFeedback 필드로 저장하며 백업 검증과 문서 내보내기에 포함했다. 빈 느낌 기록은 저장하지 않는다.

최근 두 체성분 측정 사이의 체중·골격근량·체지방량·체지방률 차이와 운동 일수·세트·유산소 분·식사 기록일·체감 기록 건수를 보여준다. 체중 단독 입력은 인바디로 세지 않으며 이전 측정일 다음 날부터 이번 측정일까지 집계한다. 측정 시간이 없으므로 하루 단위 경계라는 설명을 제공한다. 원인이나 생리적 회복을 판정하지 않는다.

검증: 165개 테스트와 빌드 통과. sandbox에서 느낌 저장 후 새로고침 복원, CSV로 예시 측정 2건 가져오기 후 차이 및 운동량 표시 확인. 모바일 390px 가로 넘침 없음. 배포하지 않음.

## 근육 위치 선택

운동 느낌에 앞·뒤 근육 위치 그림을 추가했다. SVG의 개별 부위를 클릭하거나 Enter/Space로 선택·해제한다. 선택값은 기존 workoutFeedback.muscles 형식을 유지한다. 종목별 예상 사용 부위는 파랑, 직접 선택한 느낌은 주황, 겹치는 부위는 보라로 표시한다. 종목 전환은 예상 표시만 바꾸고 직접 선택값은 유지한다. 이름은 위팔 앞/뒤, 허벅지 뒤 등 위치 표현을 사용하고 이름 선택도 보조 수단으로 남겼다. 그림은 주요 부위를 단순화한 벡터 근육도이며 실제 자극을 측정하지 않는다.

검증: 165개 기존 테스트 및 빌드 통과. 직접 SVG 경로 클릭, 키보드 토글, 종목 전환 후 선택 유지, 저장·새로고침 복원을 sandbox에서 확인. 선택 시 SVG를 다시 만들지 않고 상태만 갱신해 클릭 후 화면 위치와 초점이 바뀌지 않게 했다. 390px에서 모달 가로 넘침 없음. 배포하지 않음.

## 전체 흐름 최적화 2차

- 작성 중 활동은 계정별 sessionStorage에 보관한다. 새로고침에 복원되며 정식 저장하면 제거한다. 이 탭의 임시 보관이고 계정 동기화·백업 대상은 아니라는 안내를 표시한다. 사진 참조도 검증해 복원한다. 300ms 후 저장하고 페이지가 숨겨지거나 종료될 때 즉시 반영한다.
- 활동 수정 시 식사 금액 입력은 유지한 채 분류에 따라 활성화한다. 식사→다른 분류 전환은 연결 해제를 안내하며 숨은 금액으로 저장이 막히지 않는다. 다른 분류→식사도 지출을 추가할 수 있다. 운동에서 다른 분류로 저장하면 연결된 운동 느낌을 정리한다.
- 체중은 몸의 변화 입력에서 관리한다. 신체 정보에서는 최신 체중과 수정 바로가기를 제공해 같은 날짜의 체중을 두 곳에서 입력하지 않는다. 입력한 키를 비웠을 때 이전 키가 되살아나는 동작도 수정했다.
- 사용 근육과 체감 요약에서 위팔 앞/뒤 등 위치 명칭을 통일했다. 인바디 비교 자료가 없을 때 안내 카드를 접을 수 있게 줄였다.
- 시간표 구간 계산을 매 항목마다 하지 않고 한 번 계산해 공유한다. 선택창은 선택값·옵션이 그대로면 다시 동기화하지 않아 다른 선택창 변화 때문에 닫히는 경우를 줄인다.

검증: 167개 테스트 및 프로덕션 빌드 통과. 별도 sandbox에서 초안 내용·수동 시간의 새로고침 복원, 정식 저장 후 초안 제거, 일상→식사 금액 연결, 식사→업무 전환 및 연결 해제 확인. 13개 화면×1280/390px에서 가로 넘침·콘솔 실행 오류 없음. 실제 아이폰 카메라·실계정 간 동기화는 이번 차수에 재검증하지 않았다. 로컬 브랜치에만 반영, 배포하지 않음.

## 배포 전 최종 점검 (2026-11-01)

사용자가 오류 점검 후 배포를 요청했다. UTC 환경에서 167개 테스트 통과, GITHUB_ACTIONS=true 빌드 성공. 비공개 Toss 인증키와 과거 loopback 연결 주소가 배포 파일에 없는지 값 노출 없이 검사했다. 근육 지도 키보드 조작 후 초점은 재생성/문자열 선택자 대신 기존 요소에 유지하도록 정리했다.

운영과 동일한 /hazeflow/ 기본 경로로 preview를 실행해 예시 백업 가져오기·JSON 다운로드를 확인했다. 운동 느낌과 인바디 이력 보존 확인, 예시 데이터가 있는 13개 화면×1280/390px에서 가로 넘침과 콘솔 실행 오류 없음. 실제 아이폰 카메라 및 실계정 로그인·기기간 동기화는 물리 기기로 다시 검증한 범위에 포함되지 않는다. 서버·DB 정책 변경은 없다.
