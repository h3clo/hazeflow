# Haze Flow UI 디자인 방향 (시안 · 미적용)

> 기준일: 2026-11-09 (Asia/Seoul). **앱 코드·스키마·동기화 미변경.** PR [#3](https://github.com/h3clo/hazeflow/pull/3) 위계 개선은 보존. 사용자가 시안을 고르기 전까지 구현·병합·Pages 배포 금지.

## 목표 (2026-11-09 정정)

전체 앱은 **현대적 라이프·생산성 대시보드**다. 밝고 산뜻한 색, 부드러운 포인트, 읽기 쉬운 타이포·여백, 데이터 시각화, 중요도 위계. 카드 기계적 반복·과도한 복잡성 금지. 레트로·타자기·종이·구식 UI·잡지 마스트헤드로 **앱 전체를** 만들지 않는다.

| 영역 | 방향 |
| --- | --- |
| 전체 UI | 라이프·생산성 대시보드 (Pinterest형 밝은 레퍼런스 선호 · 이미지 별도 전달 예정) |
| Today | 간결한 대시보드 · 캡처·진행 중 우선 |
| 돌아보기 | 같은 대시보드 언어 안에서 **깊게 발견** (집계만 나열하지 않음). 잡지/포토 에세이는 전체 톤이 아님 |
| AI 사진 일기 | **해당 기능만** 포토 에세이 조판. 전체 앱에 적용 금지 |
| 공통 | 기존 기능·데이터 유지 · 데스크톱·iPhone·iPad |

## 문서에 이미 있던 것 / 없던 것

| 항목 | 상태 |
| --- | --- |
| 기록 기반 로컬 일기 초안 | 있음 (`local-draft`) |
| 외부 AI **텍스트** 일기 초안 | 로컬 개발 키 있을 때만 (`ai-draft`). Pages에는 AI 서버 없음 ([feature-coverage.md](feature-coverage.md)) |
| **사진+글을 AI가 조판해 잡지/포토 에세이 페이지로 완성** | **문서에 제품 방향으로 정리된 적 없음** → 아래 향후 아이디어로 신규 기록 |

## 향후 기능 아이디어 · AI 사진 일기 (미구현 · 미승인)

**한 줄:** 사용자가 남긴 사진과 글(일기·활동·회고)을 AI가 분석·편집해, 잡지나 포토 에세이처럼 읽히는 일기 페이지를 제안한다.

### 전제 (비전과 맞춤)
- 없는 감정·행동을 지어내지 않는다. 사용자가 고른/남긴 사진·문장만 재료로 쓴다.
- 초안은 확인 후 적용. 기존 일기·사진을 즉시 덮어쓰지 않는다.
- 외부 전송·비용·개인정보 범위는 별도 승인. 현재 Pages에는 비공개 AI API가 없다.
- UI 템플릿은 아래 시안(특히 돌아보기 스프레드)을 조판 골격으로 재사용할 수 있게 설계한다.

### 하지 말 것 (지금)
- 스키마 확장, API 연동, 앱 화면 구현, 실계정 시험.

## 시안 2개 (인터랙티브 HTML)

경로: [design-mocks/direction-a.html](design-mocks/direction-a.html), [design-mocks/direction-b.html](design-mocks/direction-b.html)  
로컬: `npx --yes serve docs/design-mocks -p 5188` 후 브라우저에서 열기. Today/돌아보기 · Desktop/iPad/iPhone 전환.

### 시안 A — Clear Desk / Soft Spread
- **느낌:** 안개 낀 초록·깊은 잉크, 둥근 캡처, Fraunces 저널 타이포.
- **Today:** 큰 한 줄 입력 + 라이브 바 + 리스트형 기록. 일정/루틴은 리본·체크(동일 카드 그리드 없음).
- **돌아보기:** 풀블리드 주간 히어로 사진 영역 + 회고 인용 상단 + 집계 details + 스냅샷 비교 안내.
- **잘 맞는 경우:** 부드럽고 매일 부담 없는 톤을 원할 때.

### 시안 B — Signal Desk / Ink Archive
- **느낌:** 잉크 선·모노스페이스 라벨·세리프 마스트헤드, 티얼 신호색 한 점.
- **Today:** 각진 데스크 모듈, 캡처 커맨드 박스, LIVE 신호 바, Day meters.
- **돌아보기:** 잡지 Vol./날짜 마스트헤드, 큰 pull quote, 사진 플레이트, 잉크 대비 AI 밴드(향후).
- **잘 맞는 경우:** 에디토리얼·아카이브 감성, 선명한 대비를 원할 때.

## 공통 유지 범위 (구현 시에도)

캡처(활동 시작/짧은 기록/기록), 라이브 운동 세션, 아젠다, 루틴·할 일, 주간 스트립→회고, 주간 회고 폼(`weeklyReviews`), 과거 비교 스냅샷·가까운 날 발견. **저장·동기화·스키마 불변.**

## 결정 (2026-11-09)

**시안 A·B·혼합 모두 채택하지 않음.** 취향과 거리가 멀어 추가 변형·기존 시안 수정도 하지 않는다. 디자인 작업은 여기서 중단한다.

이후 방향은 **사용자가 고른 레퍼런스 이미지**를 기준으로만 다시 잡는다. 그때까지 앱 CSS/마크업 리뉴얼·PR #3/#4 병합·Pages 배포를 하지 않는다.
