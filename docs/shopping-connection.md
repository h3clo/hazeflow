# 쇼핑몰 파일 연결

돈 관리 → 가계부 → 쇼핑몰 파일 연결.

## 사용

1. 추출 도구 사용법을 펼쳐 `Haze Flow 주문 추출` 링크를 PC Safari 북마크 막대로 드래그한다.
2. 네이버·쿠팡·11번가·지그재그·G마켓에서 본인 주문내역 또는 주문 상세를 열고 등록한 북마크를 실행한다.
3. 현재 화면의 주문을 CSV로 저장한다. 페이지 이동·기간 변경·더 보기로 불러오는 주문은 별도 실행해야 한다.
4. CSV·TSV·XLSX 파일을 가져오거나 열 제목을 포함한 표를 붙여넣는다. 시트와 제목 행을 변경할 수 있다.
5. 날짜·실제 결제금액·주문번호를 검토하고 필요한 주문만 선택한다. 실제 결제금액 확인 후 저장한다.

상품 가격을 결제 합계로 추측하지 않는다. 명시된 합계를 찾지 못하면 금액이 비어 있으므로 주문 상세에서 직접 확인해야 한다. 주문번호가 없거나 동일 주문번호에 서로 다른 금액이 있으면 기본 선택하지 않는다. 동일 주문번호의 같은 결제총액이 상품별로 반복될 때는 총액을 한 번만 저장한다. 취소·환불·반품·미결제 상태는 저장을 차단한다. 환불 거래를 자동 정산하는 기능은 포함하지 않는다.

파일은 기기에서 해석하고, 선택한 날짜·금액·판매처·결제수단·주문번호·상품명만 기존 가계부 기록으로 저장한다. 원본 파일·주소·연락처·로그인 쿠키를 업로드하지 않는다. 로그인 상태에서는 저장한 가계부 기록이 기존 계정 동기화 대상이 된다.

## 조사와 검증 (2026-11-02)

구매자용 공통 공식 CSV API를 확인한 것은 아니다. 알려진 외부 추출 사례는 로그인된 페이지를 엑셀 매크로/확장 프로그램으로 읽는 방식이다. 기존 도구의 쿠키 수동 복사나 외부 코드를 실행하는 기능은 추가하지 않았다.

- 제작자 설명: https://www.oppadu.com/lesson/쿠팡-네이버페이-분석/
- 제작자 최근 가이드/댓글: https://www.oppadu.com/lesson/ai-엑셀-가계부/ (쿠팡 도구는 2026-10-01 동작 중단 안내가 있어 최신 작동을 전제하지 않음)
- 네이버 공식 결제내역 안내: https://help.naver.com/service/30016/contents/22496?lang=ko&osType=COMMONOS
- 쿠팡 공식 개발자 API: https://developers.coupang.com/ko/api (판매자 API이며 개인 구매내역 API와 다름)

사용자가 로그인해둔 Mac Safari에서 네이버 주문 상세의 영수증 메뉴, 쿠팡 주문목록/영수증 메뉴, G마켓 주문내역/영수증 메뉴, 11번가 주문배송조회/영수증 메뉴, 지그재그 주문배송 화면을 읽기 전용으로 확인했다. 각 사이트에서 추출 북마크를 실제 실행하는 검증은 하지 않았다. 사이트의 DOM 구조·표시 문구가 바뀌면 추출이 누락될 수 있다. 전체 구매이력 자동 연동을 보장하지 않는다.

가상 주문 XLSX로 다중 시트·제목 행 자동 인식·Excel 날짜·다섯 쇼핑몰 명칭·금액 보정·취소 차단·확인 전 저장 방지·중복 재등록 방지를 브라우저에서 검증했다. 390px 화면에서 페이지 가로 넘침 없이 표 내부 가로 스크롤을 확인했다. 자동 테스트는 CSV/TSV 금액 구분, 주문별 묶음, 중복, 날짜/상태/통화 검증, 추출 금액 근거, 북마크 코드 구문을 검증한다.

## 소비 패턴

가계부의 ‘상품 정보 정리’에서 상품별 품목·카테고리·총 수량/용량·단위·할인 후 금액을 확인한다. 확인한 상품만 전체 기간의 소비 패턴에 반영하며 주문 총액과 미배분 금액을 구분한다. 동일 품목과 단위의 기록된 구매일 간격, 첫 구매일과 최근 구매일의 단위가격을 비교한다. 구매 간격은 소진 기간을 의미하지 않는다. 상품별 가격이 없는 수집 파일에 주문 총액을 임의로 배분하지 않는다. 상품상세는 JSON 백업과 가계부 CSV에서 보존된다.

여러 기간 파일은 한 번에 최대 20개·총 20MB·5,000행까지 검토할 수 있다. 여러 시트가 있는 엑셀은 하나씩 선택하여 시트를 확인한다. 파일 사이 같은 주문의 날짜·금액이 다르면 기본 선택하지 않는다.

## 품목별 가격·구매 간격 차트

가계부 → 소비 패턴 → 비교할 품목에서 같은 품목·단위를 선택한다. 전체 기간의 확인된 상품별 금액과 총 수량으로 단가를 계산하고, 실제 기록 날짜 간격으로 가격 선을 배치한다. 같은 날 여러 건은 수량 가중 단가를 쓴다. 구매 간격 막대는 이전 구매일로부터 지난 일수이며 평균 간격을 함께 표시한다. 모든 수치는 표로도 펼칠 수 있다. 미정리 상품은 포함되지 않으므로 차트를 완전한 소비·물가 이력으로 해석하지 않는다.

## 반복 수집과 변경 확인

쇼핑몰 계정의 상시 자동 조회가 아니라 파일 기반 갱신이다. 최근 3~6개월을 겹쳐 가져와 새 구매와 취소를 확인한다. 기존 쇼핑몰+주문번호가 있으면 신규 주문으로 중복 추가하지 않는다. 기존 주문과 날짜/최종 결제금액이 다르면 전후 값을 보여주고 사용자가 따로 선택한 변경만 갱신한다. 분류·상품별 정리·사진은 그대로 보존한다. 복합결제 또는 상품별 금액배분이 새 주문총액에 맞지 않으면 갱신을 차단한다. 열어둔 사이 기존 금액이 바뀌면 다시 미리보도록 한다.

취소/환불 상태는 기존 주문 변경 검토에 표시하되 자동으로 0원 처리하거나 수입으로 더하지 않는다. 전체/부분 환불, 환불일 및 실환불액은 상세 자료에서 확인해야 한다. 파일 사이 충돌과 기존 동일 주문 여러 건은 보류한다. 주문번호가 없는 행은 날짜/상호/금액 중복 검사만 가능하고 기존 주문 갱신 대상으로 삼지 않는다.
