# 연간 소비·세금 자료

돈 관리 → 소득·세금에 기존 소득 자료와 별도로 연말정산 소비·세금 패널을 둔다. 직접 등록/수정/삭제/되돌리기와 Haze Flow 양식 CSV 미리보기·가져오기·내보내기를 지원한다. 홈택스 원본 PDF 자동 파서나 계정 자동 연결은 아직 없다.

명의자별 연간 합계를 보관한다. 같은 명의자·귀속연도·항목은 하나이며 가져올 때 동일한 자료는 건너뛰고 다른 금액은 보류한다. 다른 가족 자료와 조회한 일부 월을 연간 본인 금액으로 잘못 저장하지 않도록 원본의 인적사항·귀속연도·조회기간을 확인한다. 간소화 카드 사용액은 공제자료 기준으로 전체 실제 소비와 다를 수 있다. 없는 항목을 0원으로 추측하지 않는다.

신용/직불/현금영수증, 보장성보험료, 의료비, 교육비, 국민연금, 실손의료보험금, 주택담보대출 이자, 주택마련저축 납입액은 각각 독립 항목이다. 서로 중복되거나 저축·보험금 수령처럼 소비가 아닌 항목이 있으므로 전체 지출로 합산하지 않는다. 결정세액/기납부세액/차감징수세액은 국세·지방세를 구분한다. 차감징수는 양수 추가납부/음수 환급으로 저장하되 실제 입출금일의 거래로 만들지 않는다. 실제 납부·환급 상세 내역은 별도 수집·대조가 필요하다.

검증된 `taxDocument`를 메모 로그로 저장하므로 기존 동기화·JSON 백업을 사용한다. 일상 활동 목록과 가계부 합계에는 들어가지 않으며 등록일 MD에 별도 포함한다. 민감한 추가 CSV 열은 저장하지 않는다. CSV 양식은 홈택스가 직접 제공하는 형식이라는 뜻이 아니다. 편집/삭제는 계정과 원본 스냅샷을 확인한다.

로컬 파일 전달은 기존 loopback opener·일회성 토큰·미리보기 제한을 그대로 유지하며 `tax` 종류를 추가했다. 전달만으로 저장하지 않는다.

## 실제 납부·환급

실제 납부일/환급일·세목·금액·출처·중복 확인용 기록키를 `taxPayment` 메모 로그로 보관한다. 납부와 환급을 별도 차트로 집계하고 올해는 현재까지로 표시한다. 연간 귀속자료와 가계부 합계에는 더하지 않는다. CSV 미리보기·중복/변경 보류·수정/삭제/되돌리기·계정 및 오래된 편집창 보호를 지원한다.

같은 날짜·세목·금액이라도 서로 다른 납부건은 실제로 있을 수 있으므로 출처+기록키로 구분한다. 수집한 납부번호 원문은 앱에 넣지 않고 로컬에서 일방향 해시한 키를 사용한다. 수동 기록은 무작위 키를 만든다. 홈택스 개인 납부 조회 0건을 급여 원천징수세액 0원이나 세금 전체 0원으로 해석하지 않는다.

## 가족 자료 보기

기존 명의자가 없는 자료는 본인으로 유지한다. `person`은 선택 필드이며 명의가 있는 가족 자료는 별도 키로 중복을 검사한다. CSV의 자료명의 열을 지원하고, 원본/CSV에서 주민번호·계좌·납세자 식별번호는 저장하지 않는다.

가족 전체를 기본으로 본인 및 등록 명의자별로 목록과 차트를 함께 거른다. 같은 연도·항목이라도 명의자가 다르면 독립 자료이고, 가족 전체 차트는 등록된 명의자 자료를 합산한다. 같은 명의자의 중복 합계는 제외한다. 가족 자료가 일부 없다고 0원 또는 가족 전체 실제 소비라고 판단하지 않는다.

자료명의는 카드 사용자·보험 계약자·환자 등 서류 기준이다. 가족 공용 지출 여부나 실제 부담자를 뜻하지 않는다. 기존 가계부 거래를 자동으로 개인/공용으로 재분류하지 않으며, 가족 정산을 추가 소비로 만들지 않는다. 소득 자료는 계속 본인 기준이다.
