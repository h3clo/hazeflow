# 요청·제안 기능 대조 (2026-11-01)

## 반영된 핵심 흐름

- 오늘: 일정·실제 활동 시간표, 시작/종료 수정, 진행 중 표시, 짧은 메모, 사진
- 계획: 월간 캘린더, 기한 없는/오늘/미래 할 일, 중요 표시, 반복 루틴, 올해 목표·버킷리스트
- 대시보드: 포스트잇+일정 캘린더, 헤더 진입, 뒤로가기·닫기 복귀
- 기록: 일기·기록 기반 일기 초안, 과거 비교, 주간 회고, MD/이미지/사진 포함 백업
- 운동: 묶음 종목, 지난 기록·즐겨찾기, 예상 근육/직접 느낀 부위 그림 선택, 체감·힘듦, 마지막 운동 경과 시간
- 몸: 신체 정보, 인바디 사진 OCR 확인·CSV 가져오기, 측정 사이 운동·식사 회고
- 자산: 수동 잔액·보유 종목, 본인 계정 일별 토스 평가액, 코인 시세, 제공자 차트
- 계정: 이메일·비밀번호, 로그인 유지, 기존 계정 동기화

## 이번 추가분

- 쇼핑 주문 한 건의 원문 붙여넣기 → 값 제안 → 확인 저장. 주문 원문은 저장하지 않고 거래·주문번호·상품명만 보관한다. 동일 주문번호 및 기존 거래의 중복을 확인한다. 취소·환불 완료 주문은 새 지출로 추가하지 않는다.
- 복합 결제: 카드·온누리·포인트 등 2~6개 수단과 금액. 합계 일치 검증, 식사 연결 거래의 수정에서도 지원. 지출은 총액 한 번만 합산한다. CSV/JSON에 상세 보존.
- 식사 영양정보: 열량·단백질·탄수화물·지방 중 확인한 값 입력, 즐겨찾기 보관·불러오기, 절반/2배 조절, 초안 복구. 몸 변화/주간 회고에서 입력 범위와 합계 표시. 미입력과 0은 구분한다.

## 아직 남은 것과 이유

- 네이버·쿠팡·11번가 구매자 계정 자동 수집: 개인 구매 내역의 공식 연동 경로가 미확정. 판매자 API를 구매자 내역 API처럼 사용하지 않는다. 현재 대안은 주문 붙여넣기·CSV·영수증 사진이다.
- 음식 이름/사진만으로 열량·영양소 자동 산정: 식품/제품·섭취량 확인과 영양 데이터 출처 연결 필요. 현재는 확인한 값을 재사용한다.
- 유산소/혼합 운동 칼로리·정확한 회복 완료 시간: 기구별 강도·휴식 등 충분한 입력과 검증이 필요. 추정한 사용 근육/경과 시간을 실제 자극·회복 측정으로 표현하지 않는다.
- 결제 취소·부분 환불·할인 충전 원장 및 카드 내역 자동 매칭: 별도 거래 관계·일자별 순지출 처리 설계가 남았다. 새 주문으로 중복 추가하지 않도록 현재 단계는 차단·안내한다.
- 앱 공유로 영수증 가져오기·푸시 알림·배포 가능한 네이티브 앱: 네이티브 기반은 있으나 iOS 개발 약관 승인, 서명 및 실기기 검증 등이 남았다. 자동으로 약관에 동의하거나 인증정보를 바꾸지 않는다.
- 아이폰 실제 촬영 문제: 사진 선택·처리/오류 안내는 구현됐으나 실제 기기에서의 최신 재검증이 필요하다.
- 외부 AI 일기: 로컬 개발 서버 키 설정 방식은 있으나 GitHub Pages 자체에는 비공개 AI API 서버가 없다. 기록 기반 로컬 초안은 사용 가능하다.
