# 공부 흐름

기록 → 공부 흐름에서 영어·개발·한국사·정처기 공부를 시작한다. 오늘 화면의 ‘공부 이어가기’로도 들어갈 수 있다. 복습 날짜가 된 질문은 오늘 화면 버튼에 개수를 표시한다.

1. 과목을 고르면 직전 기록의 ‘다음 할 것’을 시작 내용으로 제안한다. 시작 날짜와 시간을 바꿀 수 있다.
2. 마치기를 누르면 활동 종료부터 저장한다. 마무리 창을 닫아도 종료는 취소되지 않는다. 한 줄 결과와 다음 행동은 나중에 보완할 수 있다.
3. 다시 볼 내용만 질문·답·복습 날짜로 남긴다. 답은 접어두고, 기억남/다시 보기/복습 마침을 직접 선택한다. 7일·1일 간격은 고정된 편의 설정이며 학습 효과를 판정하지 않는다.
4. 노트는 미리 본 뒤 MD 다운로드·복사·Obsidian 새 노트 생성 요청 중 하나로 넘긴다. 앱 생성은 설치된 Obsidian과 보관함 이름이 필요하며 생성 성공 여부는 Haze Flow에서 확인할 수 없다. 기존 노트 덮어쓰기 옵션을 보내지 않는다. 긴 URI는 MD로 안내한다.
5. 설명하고 싶은 내용은 글감으로 모은다. 초안은 사용자가 적은 결과·질문·글감으로 만든 Markdown 뼈대다. 외부 AI 호출이나 블로그 발행은 하지 않는다. 초안에서 개인 Obsidian 주소를 제외한다.
6. Obsidian의 ‘Obsidian URL 복사’와 블로그 글 주소를 기록에 연결하면 다시 열 수 있다. 링크 등록은 외부 내용의 동기화나 발행 확인을 뜻하지 않는다.

공부 메타데이터는 기존 활동 로그의 `study`에 붙어 별도 활동을 만들지 않는다. JSON 백업·기존 계정 동기화·일별 MD에 보존한다. 활동 분류를 공부 이외로 바꾸면 공부 전용 정보는 제거한다. 삭제와 되돌리기는 기존 활동 기록 기능을 사용한다.

시간 통계는 실제 기록 구간을 사용하며 진행 중인 시간은 합계에서 뺀다. 자동 종료 구간에는 휴식이 포함될 수 있어 사용자가 활동 시간 수정으로 조정한다. 여러 기기에서 복습한 뒤 오래 열린 메모를 저장해도 변경하지 않은 최신 복습 날짜를 유지한다.

Obsidian URI 동작: https://help.obsidian.md/Extending+Obsidian/Obsidian+URI

검증: 합성 데이터로 시작·마침·마무리·다음 행동 제안·복습 일정 이동·시간 수정 후 정보 유지·새로고침 유지·MD/블로그 초안 다운로드를 브라우저에서 확인했다. 실제 보관함의 노트 생성과 실제 블로그 발행은 수행하지 않았다.

## 과목 관리

기본 네 과목 외에도 과목 추가·이름 변경·보관·다시 꺼내기를 지원한다. 최대 50자 이름을 사용하며 보관된 과목까지 같은 이름의 재추가를 막는다. 과목은 고유 식별자로 연결하고, 과거 이름 문자열만 있는 기록도 기본 과목에 연결한다. 이름 변경은 원문이나 복습·글감을 덮어쓰지 않고 표시 이름과 새 내보내기에 반영한다.

보관한 과목은 새 공부 시작 목록에서만 숨긴다. 진행 중인 공부, 과거 기록 편집, 복습 질문, 글감과 노트 링크는 유지한다. 과목 설정은 별도 `studySubjects` 동기화 단위로 저장하고 JSON 백업·복원에 보존한다. 이전 백업에 과목 목록이 없어도 기본 네 과목을 표시한다.
