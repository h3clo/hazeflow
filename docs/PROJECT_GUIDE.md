## 6. 남은 작업 — 이 문서에서 관리

- [ ] IndexedDB 이전 후 오프라인 작성→재연결, 앱 복귀·재시작, 전송 실패/공간 부족 안내를 실사용 조건에서 점검.

- [ ] 앱이 닫혀도 오는 예약 웹 푸시: 비공개 서버, 구독/해지, 기기·계정 분리, 예약 전송, 실기기 테스트.
- [ ] 식품/제품/섭취량 확인을 포함한 영양 데이터 자동 입력.
- [ ] 외부 AI 일기 서버: 비밀키·비용·전송 데이터와 사용자의 선택을 명확히 한 뒤 연결.
- [ ] 쇼핑몰 공식 구매자 연동 또는 검토 가능한 재수집 방식. 판매자 API를 개인 주문 조회 API로 오인하지 않기.

### P4 · 나중에 할 설치형 앱

- [ ] iPhone/iPad/Android 서명·SDK·다운로드/공유·사진·인증 복귀·배포.
- [ ] iOS Live Activities/Android 진행 중 알림의 타이머와 제어 버튼.
- [ ] 건강 자동 연동, 공유로 영수증 가져오기, 백그라운드/실기기 검증.

Capacitor 프로젝트가 있다는 사실은 사용 가능한 앱 배포가 끝났다는 뜻이 아니다. 웹 안정화와 기존 자료 정리를 먼저 한다.
