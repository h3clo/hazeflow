# 주문 영수증 대조 — 기존 도구 (레거시)

> 이 문서는 기존 쿠팡 쇼핑 영수증 대조 스크립트의 사용법이다. 새 소비 데이터 방향은 [결제 원장 중심 설계](payment-ledger-plan.md)를 따른다. 은행·카드사·현금영수증의 결제 증빙을 먼저 정리하고, 쇼핑몰 주문·영수증을 연결해 상품을 보완한다. 카드 승인·매입, 계좌 출금, 카드대금 납부, 현금영수증이 같은 소비를 가리킬 수 있으므로 별도 지출로 합산하지 않는다. 주문·결제는 다대다 관계일 수 있고, 미연결 결제의 구매처는 사용자에게 확인받는다. **이 스크립트가 새 결제 원장 전체를 구현한 것은 아니다.**


쇼핑몰 영수증은 판매자별로 나뉘거나 카드·현금영수증에 함께 나타날 수 있습니다. 영수증 합계는 확정 소비로 취급하지 않습니다. 현재 주문 상태, 부분 취소, 환불, 포인트 및 다른 결제수단을 대조한 뒤 기존 쇼핑 가져오기 미리보기로 반영합니다.

저장된 쿠팡 JSON 자료는 다음 명령으로 비공개 결과 폴더에 정리할 수 있습니다.

```sh
node scripts/reconcile-shopping-receipts.mjs 원본폴더 결과폴더 YYYY-MM-DD
```

입력은 `쿠팡-YYYY-카드영수증[-N].json`, `쿠팡-YYYY-현금영수증.json`의 `rows`이며 `date`, `orderId`, `item`, 양의 정수 `amount`를 사용합니다. 선택적으로 `receiptId`를 보관하면 명백한 중복만 제거합니다. 번호가 없는 동일 행은 서로 다른 판매자의 영수증일 수 있어 임의로 제거하지 않습니다.

`쿠팡-취소반품-확인페이지.json`의 `pages`는 화면에서 읽은 취소 목록 텍스트입니다. `complete`는 실제 전체 수집을 마쳤을 때만 true로 기록합니다. 해당 주문이 발견되면 전체 주문을 보류하고, 목록의 상품 가격을 환급액으로 추정해 차감하지 않습니다.

결과 JSON·설명 문서는 원본 폴더 바깥 또는 비공개 폴더에 저장합니다. 이 명령은 원본이나 Haze Flow 계정에 쓰지 않습니다. 개인 자료와 결과는 저장소에 커밋하지 않습니다.
