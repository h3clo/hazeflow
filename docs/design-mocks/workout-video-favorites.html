운동 영상 즐겨찾기 — 어떻게 바뀌면 좋은지

헬스장에서 체스트프레스를 끝내고, 이어서 볼 홈트 영상을 검색하지 않고 바로 여는 흐름. 기존 「식사·운동 즐겨찾기」에 영상(링크)만 얹는 안입니다. 새 메뉴·유튜브 로그인·전체 UI 교체는 하지 않습니다.

범위: 시안만. 스키마·동기화·앱 코드 구현 없음. 채택 후 작은 묶음으로 구현.

1. 지금 (문제)

세션에는 세트·한 줄 추가만 있고, 자주 보는 영상은 유튜브 앱을 따로 찾아 들어가야 합니다.

3. 저장 화면 (링크형)

식사/운동 텍스트 즐겨찾기와 같은 편집창. 분류에 「영상」을 추가하고 URL만 받습니다.

편집닫기

즐겨찾기로 저장

앱 안에 영상을 재생하지 않아요. 열기를 누르면 유튜브로 나가요. 자동 재생·추천·계정 연동 없음.

4. 즐겨찾기 목록

기존 「식사·운동 즐겨찾기」화면에 영상 칩만 추가. 홈트·등산 시즌에도 같은 자리에서 고릅니다.

즐겨찾기＋

자주 쓰는 식사·운동·영상

불러와서 오늘 양만 바꾸거나, 홈트 링크를 바로 열어요.

오늘 같은 날의 흐름 (시나리오)

  1. 근력 세션 시작 → 어시스트풀업·체스트프레스 세트 표시
  2. 컨디션상 계획 변경 → 체스트프레스만 마치고 홈트로 전환
  3. 세션 카드의 이어서 볼 영상에서 저장해 둔 링크 열기
  4. (선택) 활동은 「운동」으로 유지하고 메모/한 줄에 유튜브 홈트 15분만 남김
