# 토스 조회 연결 (현재 로컬 준비 단계)

공식 OpenAPI 명세: https://openapi.tossinvest.com/openapi-docs/latest/openapi.json

## 현재 상태

- 사용자가 직접 새 키를 발급했고, 발급 직후 표시된 원본 두 개를 비공개 로컬 설정에 저장했다. 키 원문을 채팅/터미널 로그/저장소에 출력하지 않았다.
- 실제 공식 API로 인증·보유 종목·현재가·USD/KRW 매매기준율 조회에 성공했다. 거래/주문 요청 없음.
- Supabase에 존재하는 단일 Haze Flow 계정의 이메일을 소유자로 제한했다. `.env.toss.local`은 gitignore 및 0600 확인.
- 자산 화면의 토스 조회는 이 맥의 127.0.0.1 조회 서버로 연결된다. 맥에서 서버가 실행 중이어야 하며 휴대폰/다른 기기 상시 연결은 아직 미구현.
- 토스 주식 평가액은 별도로 보여준다. 기존 수동 투자 잔액과 중복 합산하지 않으며 총자산 자동 재평가는 아직 합치지 않았다.

## 이 맥에서 준비된 연결 코드

`npm run toss:local`로 127.0.0.1:8788에서 실행. 터미널에 출력되는 일회 설정 주소를 Safari에서 연다. 포트는 이 맥에만 바인딩한다.

로컬 설정 화면에서 키 두 개와 Haze Flow 이메일을 입력해 저장한다. `.env.toss.local`(gitignore)에 0600 권한으로 보관하며 임시 파일을 쓴 뒤 원자적으로 교체한다. 키는 웹 번들/응답/로그에 넣지 않는다. 설정은 서버 실행 때 생성한 nonce와 동일 Origin을 확인한다.

연결 확인은 공식 `/oauth2/token`, `/api/v1/accounts`, `/api/v1/holdings`, `/api/v1/prices`, `/api/v1/exchange-rate`만 사용. 주문/환전/송금 API 경로는 없다. 토큰은 메모리에 캐시하고 중복 발급 방지, 조회 결과는 30초 캐시한다. 현재 키를 사용하는 다른 프로그램이 있으면 토큰 재발급에 따른 무효화에 유의해야 한다.

평가액은 보유 수량 × 조회 현재가 × 통화별 환율로 계산. USD는 매매기준율(midRate)을 사용하고 환율 누락/다른 통화는 오류로 처리한다. 매수 환율을 평가 환율로 대신 사용하지 않는다. 계좌번호는 끝 4자리만 응답하며 조회 시각과 시세 시각을 구분한다. 예수금/코인/다른 자산을 포함한 총자산이 아니라 **보유 주식 평가액**이다.

향후 웹/앱용 `/portfolio`는 Supabase `/auth/v1/user`로 토큰을 검증하고 로컬 설정의 소유자 이메일과 일치하는 계정만 허용한다. 사용자 입력 URL로 임의 요청을 전달하는 프록시는 제공하지 않는다.

## 남은 작업

1. 웹 자산 화면에서 로그인한 본인만 조회되는지와 브라우저 로컬 네트워크 접근 검증.
2. 개인용 조회 이용료/약관 조건을 최종 확인. 유료 서버/플랜을 가입하지 않았다.
3. 아이폰·다른 기기에서 접근할 개인 서버 주소/고정 IP 또는 이 맥의 중계 방식 결정. 현재 loopback 주소는 다른 기기에서 접근할 수 없다.
4. 자산 화면 연결, 기존 수동 투자액과 중복 합산 방지, 일별 평가 기록/차트.
