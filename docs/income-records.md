# 연간 소득 자료

돈 관리 → 소득 자료에서 직접 등록하거나 Haze Flow 소득 CSV 양식을 가져온다. 귀속연도·소득 종류·자료 범위·총급여/수입금액·소득금액·결정세액·출처·메모만 보관한다. 주민번호·주소·인증정보·문서 발급번호·원본 PDF는 필요하지 않다. 원본 전체를 앱에 붙여넣지 않는다.

이 기능은 국세청 계정 자동 연동이나 PDF 자동 추출 기능이 아니다. 파일에서 확인한 숫자를 정해진 CSV 열로 정리한 뒤 미리보기로 확인해 저장한다. 제목 열의 별칭을 지원하며 알 수 없는 열은 저장하지 않는다. CSV 양식에 없는 실제 국세청 PDF·엑셀 서식의 자동 인식은 검증하지 않았다.

- 실제 입금 수입은 기존 가계부에서 관리한다. 이 자료는 그 합계에 더하지 않는다. 세전/신고 수입을 실수령액으로 계산하거나 연간 금액을 12개월에 배분하지 않는다.
- 소득 종류별로 수입금액 차트를 분리한다. 소득금액을 수입금액 대신 쓰지 않으며 미입력·확인된 0원·음수 사업 소득금액을 구분한다.
- 같은 해·종류에 연간 합계가 있으면 회사별 자료 대신 그 합계를 사용한다. 중복 합계나 금액 누락은 차트에서 제외하고 알려준다. 재발급 자료가 기존 자료와 다르면 덮어쓰지 않고 보류한다.
- 연간 합계는 해당 종류의 그 해 총액이어야 한다. 이전 근무지 금액이 합산된 원천징수영수증을 별도 회사분과 중복 등록하지 않는다. 국세청 ‘종합소득세 신고 현황’과 ‘연말정산 현황’을 무조건 합산하지 않는다.
- 여러 소득 종류가 있는 증명서의 총결정세액은 종류별로 임의 배분하지 않는다. 종류별 세액이 없으면 비워두고 메모에 합계를 적는다.
- 수정·삭제·되돌리기, CSV 내보내기를 지원한다. 등록 날짜를 가진 메모 로그에 `incomeDocument`를 붙여 기존 동기화·JSON 백업을 사용한다. 실제 활동 목록/시간 통계에는 넣지 않는다. 등록 날짜의 MD에는 별도 소득 자료 항목으로 포함한다. 신규 동기화 컬렉션이나 SQL 변경은 없다.
- 같은 계정의 다른 화면에서 자료가 바뀐 경우 오래 열린 편집 창의 저장·삭제를 차단한다. 계정 전환 시 열린 창은 기존 동작대로 닫힌다.

## 국세청 조회 확인 (2026-11-03)

사용자가 직접 홈택스 본인인증을 마친 상태에서 소득금액증명 인터넷열람을 확인했다. 과세기간 범위는 한 요청에 5년 이내라는 화면 안내에 따라 2015~2019, 2020~2024, 2025로 나눠 신청했다. 실제 2015~2025 귀속 자료가 열렸으며 필요한 근로·사업소득 합계만 별도 비공개 로컬 자료로 정리했다. 개인 금액·식별자·문서 화면은 이 저장소에 넣지 않는다. 2026년 연간 소득은 수집하지 않았다. 다른 사용자나 모든 소득 종류/미신고 소득의 조회 범위를 보장하지 않는다.

공식 서비스: https://www.hometax.go.kr/

## 검증

합성 CSV 4건 가져오기, 연간 합계/회사별 중복 합산 방지, 수정 시 차트 재계산, 삭제 후 되돌리기, 활동 건수/가계부 수입 합계에 영향 없음, 새 탭에서 유지됨을 브라우저에서 확인했다. 자동 검사는 소득 자료 검증·동기화/백업·MD·CSV 왕복·불필요한 열 제외·충돌 보류·서로 다른 소득 종류 차트 분리를 확인한다.
