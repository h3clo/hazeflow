# Haze Flow

계획과 반복 루틴을 확인하고, 실제 생활 기록을 남긴 뒤 날짜별로 돌아보는 로컬 웹앱.

```sh
npm install
npm run dev
```

http://localhost:5173 에서 실행된다. 별도 기기에 자동 동기화되지 않으므로 상단 내보내기에서 JSON 백업을 보관한다.

## 기본 흐름

1. 루틴 설정에서 반복할 요일·시간·단계를 한 번 정한다.
2. 오늘과 주간 계획에 해당 날짜의 루틴과 일정을 표시한다.
3. 오늘 화면에서는 실행한 단계만 체크한다. 해당 날짜의 실행 기록은 다음 날과 분리된다.
4. 한 줄 기록으로 식사·운동·일상을 남긴다. 입력 원문은 보관한다.
5. 기록 모아보기의 날짜·분류·검색과 일기에서 하루를 돌아본다.

운동 표기: 중량 운동은 kg/횟수/세트, 마이마운틴은 각도/속도/분, 러닝머신·천계는 속도/분.

## 확인

```sh
npm test
npm run build
```

앱 주소 뒤에 `?sandbox=1`을 붙이면 실제 기록과 분리된 점검 공간이 열린다.

AI 초안은 로컬 Vite 서버가 OPENAI_API_KEY를 환경 변수로 받은 경우에만 생성할 수 있다. 키를 프론트엔드 파일이나 VITE_ 변수에 넣지 않는다. 정적 빌드만 배포하면 AI 서버 경로는 제공되지 않는다.

기록과 반복/실행 규칙은 domain.js, 화면과 입력 흐름은 app.js, 회귀 검사는 tests/domain.test.js에 있다. [점검 기록](docs/function-check.md) 참고.

## 사진 기록

활동과 일기에 사진을 최대 8장씩 첨부한다. 사진만 남기는 기록도 가능하며 긴 쪽 1600px JPEG로 변환해 브라우저 IndexedDB에 저장한다. 원본 파일 보관 용도는 아니다. JSON 백업에는 실제 사진을 포함하고, 사진이 있는 문서 내보내기는 MD와 photos 폴더를 ZIP으로 묶는다. PNG에도 사진을 포함한다. 브라우저 데이터 삭제 전에 JSON 백업을 내려받아 보관한다.

## 과거 비교 · 주간 회고 · 즐겨찾기

과거 비교에서 두 날짜를 직접 선택하거나 한 달/일 년 전을 고르면 사진·일기·활동·생활 수치·같은 운동을 나란히 확인한다. 주간 회고는 월~일 기준이며 오늘까지의 계획과 실행, 기록한 날, 운동 일수, 식사 건수, 기분 및 수면 만족도/기운/스트레스 평균을 정리한다. 기록하지 않은 값을 추정하지 않는다. 회고 메모와 식사·운동 즐겨찾기는 JSON 백업과 전체 문서에 포함한다. 즐겨찾기를 불러온 후에는 내용과 시간을 확인하고 기록하기를 눌러 저장한다.

## GitHub Pages

공개 주소: https://h3clo.github.io/hazeflow/

main에 push하면 GitHub Actions가 검사 및 Vite 빌드 후 Pages에 배포한다. Actions 빌드에서는 base=/hazeflow/를 사용한다. 소스 코드만 공개하며 개인 기록과 사진은 서버로 보내지 않는다. 정적 Pages 버전은 AI 일기 서버를 제공하지 않는다.

localhost와 GitHub Pages의 브라우저 저장소는 별개다. 기존 기록은 localhost의 내보내기 → 전체 기록·복원용 백업(JSON)을 받은 뒤 새 주소의 백업 불러오기로 이동한다. 사진·즐겨찾기·주간 회고도 포함된다. 기기 간 자동 동기화는 제공하지 않는다.
